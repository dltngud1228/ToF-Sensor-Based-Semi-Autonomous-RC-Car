# 주행 알고리즘

## 수동 모드

수동 모드에서는 블루투스로 받은 명령을 바로 실행합니다.

- `F`: 전진
- `B`: 후진
- `L`: 좌회전
- `R`: 우회전
- `S`: 정지
- `M`: 반자율 모드로 전환

## 반자율 모드

`M`으로 반자율 모드에 진입한 뒤 `F`를 입력하면 주행을 시작합니다.

1. 전방 거리 측정
2. 300mm보다 멀면 전진
3. 300mm 이내이면 정지
4. 센서를 왼쪽 150도로 이동해 거리 측정
5. 센서를 오른쪽 30도로 이동해 거리 측정
6. 센서를 정면 90도로 복귀
7. 더 넓은 방향으로 회전
8. 다시 전방 거리 측정

## ㄷ자 장애물

왼쪽과 오른쪽 거리가 모두 300mm 이하이면 ㄷ자 장애물에 갇힌 것으로 판단합니다.

```text
후진 3000ms
좌회전 3000ms
전진 1500ms
우회전 3000ms
전진
```

## 주요 조정값

`rc_car_main.ino` 상단에서 다음 값을 조정할 수 있습니다.

```cpp
int obstacleDistance = 300;
int centerAngle = 90;
int leftAngle = 150;
int rightAngle = 30;
```

회피 회전 시간은 `avoidObstacle()`의 `delay(900)`에서 조정합니다.
