# 블루투스 명령어

| 앱 버튼 | 전송 문자 | 수동 모드 | 반자율 모드 |
|---|:---:|---|---|
| 전진 | `F` | 계속 전진 | 장애물 회피 주행 시작 |
| 후진 | `B` | 계속 후진 | 자동 주행 중지 후 후진 |
| 좌회전 | `L` | 제자리 좌회전 | 자동 주행 중지 후 좌회전 |
| 우회전 | `R` | 제자리 우회전 | 자동 주행 중지 후 우회전 |
| 정지 | `S` | 정지 | 자동 주행 중지 및 정지 |
| 모드 변경 | `M` | 반자율 모드로 전환 | 수동 모드로 전환 |

HC-06의 기본 통신 속도는 9600bps로 설정했습니다.

App Inventor의 각 버튼을 눌렀을 때 표에 적힌 문자 한 글자를 전송하도록 구성합니다.
