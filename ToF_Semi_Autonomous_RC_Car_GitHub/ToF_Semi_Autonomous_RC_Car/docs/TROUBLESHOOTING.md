# 문제 해결

## ToF 센서 초기화 실패

1. SDA가 A4, SCL이 A5에 연결됐는지 확인합니다.
2. 센서의 VIN과 GND를 확인합니다.
3. 납땜 상태를 확인합니다.
4. `tof_sensor_test.ino`를 업로드합니다.
5. 시리얼 모니터를 9600bps로 설정합니다.
6. 거리값이 출력되는지 확인합니다.

## 장애물이 없는데 감지되는 경우

- 센서 앞의 보호 필름과 이물질을 확인합니다.
- 센서가 차량이나 브라켓을 바라보지 않는지 확인합니다.
- 서보모터의 정면 각도 `centerAngle`을 조정합니다.
- 장애물 기준값 `obstacleDistance`를 줄여 봅니다.
- 강한 햇빛이나 반사율이 낮은 검은 물체에서는 측정값이 불안정할 수 있습니다.

## 모터 작동 시 블루투스 연결이 끊기는 경우

- 모터와 제어부의 전원을 분리합니다.
- Arduino, 센서, 서보, HC-06은 안정적인 5V 스텝다운에 연결합니다.
- 모터 드라이버는 6V 스텝다운에 연결합니다.
- 모든 GND를 공통으로 연결합니다.
- 배터리 및 전원선의 접촉 상태를 확인합니다.
- 모터 전류를 점퍼선으로 흘리지 않습니다.

## 한쪽 모터가 움직이지 않는 경우

- 모터를 반대쪽 드라이버 출력에 연결해 모터 자체를 확인합니다.
- 모터 드라이버의 입력 신호를 확인합니다.
- 드라이버 IC의 발열이나 손상 흔적을 확인합니다.
- 전원을 끈 상태에서 배선을 다시 확인합니다.

## 회전각이 맞지 않는 경우

시간 기반 회전은 바닥 마찰, 배터리 전압과 차량 무게에 따라 달라집니다.

- 일반 회피 회전: `delay(900)`
- ㄷ자 좌회전: `delay(3000)`
- ㄷ자 우회전: `delay(3000)`

차량의 실제 움직임을 보면서 값을 조정합니다.
